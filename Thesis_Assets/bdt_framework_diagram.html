Neuro-DT — Framework Diagram Review

One framework, run as two experiments — not two diagrams

Figure 7.1 from the proposal describes the system's architecture, not the hardware it happened to run on. CPU and GPU are two runs of the identical pipeline below — the difference is completeness (1 of 5 folds vs. 5 of 5, plus the full ablation study), which belongs in the Experimentation chapter's results, not in a second diagram.

1

Single diagram. Every box below — the CNN+Transformer classifier, the Markov engine, SHAP/Grad-CAM, the dashboard — is the same component on both runs. What changed between the CPU and GPU experiments is how far execution got (folds completed, ablation run or not), which is a results-table fact, not an architecture fact.
